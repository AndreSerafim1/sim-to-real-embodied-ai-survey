# 5. System Identification and Simulation Fidelity

This section contains research on improving simulation accuracy through physical modeling, system identification, and calibration using real-world observations.

## Si et al. (2024)

**Title:** DiffTactile: A Physics-Based Differentiable Tactile Simulator for Contact-Rich Robotic Manipulation

**Publication:** International Conference on Learning Representations (ICLR)

**Relevance:** Introduces a differentiable tactile simulator that enables physical parameter estimation and improves the modeling of contact-rich robotic interactions.

## Liang et al. (2024)

**Title:** Real-to-Sim Deformable Object Manipulation: Optimizing Physics Models with Residual Mappings for Robotic Surgery

**Publication:** IEEE International Conference on Robotics and Automation (ICRA)

**DOI:** https://doi.org/10.1109/ICRA57147.2024.10610263

**Relevance:** Investigates physics model calibration and residual mappings to improve the simulation of deformable materials in robotic surgery.

## Xu et al. (2026)

**Title:** A Real-Sim-Real Loop Framework for Generalizable Robotic Policy Transfer

**Publication:** IEEE Robotics and Automation Letters

**DOI:** https://doi.org/10.1109/LRA.2026.3744989

**Relevance:** Proposes an iterative framework that incorporates real-world observations into simulation-based learning to improve robotic policy transfer.
